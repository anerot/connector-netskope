#### Following enhancements have been made to the Netskope connector in version 2.0.0:

- The APIs used in the connector's previous version connector are now deprecated. The
connector has been redeveloped with the new APIs (v2).
- The following actions and playbooks have been added:
    - Get Alerts List
    - Get Events List
    - Create URL List
    - Get All URL List
    - Get URL List Details
    - Add URL List
    - Update URL List
    - Delete URL List
    - Get Client List
    - Execute an API Request
